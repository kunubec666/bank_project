## Модуль декораторов (Decorators)
Реализован декоратор `@log`, который автоматически регистрирует детали выполнения функций:
- Логирует успешное выполнение функции и её результат.
- Логирует возникшие ошибки (тип исключения и входные параметры).
- Принимает необязательный аргумент `filename` для записи логов в файл. Если аргумент не задан — выводит логи прямо в консоль.

### Тестирование декораторов
Все сценарии успешно протестированы с использованием фикстур `capsys` и `tmp_path`. Код покрыт тестами более чем на 80%. Для генерации отчета выполните:
```bash
poetry run pytest --cov=src --cov-report=html
```
