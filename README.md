# Виджет банковских операций клиента

## Описание проекта
Бэкенд-часть для нового виджета личного кабинета крупного банка. Проект предназначен для подготовки, фильтрации, сортировки и отображения данных о последних успешных банковских операциях клиента.

## Функциональность
*   **Маскировка карт:** Отображает первые 6 и последние 4 цифры номера карты в формате `XXXX XX** **** XXXX`.
*   **Маскировка счетов:** Отображает только последние 4 цифры номера счета в формате `**XXXX`.
*   **Универсальный виджет:** Автоматически распознает тип продукта (карта или счет) и маскирует его, сохраняя текстовое название (например, *Visa Platinum*).
*   **Фильтрация и сортировка:** Реализованы функции фильтрации транзакций по их статусу (например, `EXECUTED`) и сортировки операций по дате.
*   **Форматирование дат:** Преобразование строк ISO-формата в читаемый формат `ДД.ММ.ГГГГ`.

## Установка и использование

### Требования
*   Python 3.10 или выше
*   Poetry (менеджер зависимостей)

### Пошаговая установка
1. Клонируйте репозиторий с GitHub:
   ```bash
   git clone git@github.com:kunubec666/bank_project.git
   ```
2. Перейдите в папку проекта:
   ```bash
   cd bank_project
   ```
3. Установите зависимости и виртуальное окружение через Poetry:
   ```bash
   poetry install
   ```

```python

```

## Качество кода и линтинг
В проекте настроены инструменты статического анализа и автоматического форматирования кода в группе `lint`:
*   **Flake8** — проверка стиля кода (конфигурация в `.flake8`)
*   **Black** — автоматическое форматирование кода
*   **isort** — сортировка импортов
*   **mypy** — проверка строгой типизации

Для запуска автоматического форматирования и проверки используйте команды:
```bash
poetry run isort src/
poetry run black src/
poetry run flake8 src/
poetry run mypy src/
```
